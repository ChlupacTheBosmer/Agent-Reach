# Update Agent Reach

Installing and updating now use one guide. Follow [install.md](https://raw.githubusercontent.com/ChlupacTheBosmer/Agent-Reach/custom/docs/install.md) from step 0: it checks the installed version and updates, or upgrades from 1.5 and earlier, as needed. Updates install this fork with `uv tool install --force git+https://github.com/ChlupacTheBosmer/Agent-Reach@<commit-or-tag>`: pin a commit or tag you have reviewed, never a moving `latest` link.
